# Clive Musika - WDD430 Portfolio

A personal portfolio website built with Next.js, TypeScript and Tailwind CSS for BYU-Idaho WDD 430.

**Live site:** https://wdd430-portfolio-sepia.vercel.app/

## Features

- Home page with project cards
- About page
- Reusable components (Header, Footer, ProjectCard, ProjectList, SkillCard)
- `/api/hello` API route

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
